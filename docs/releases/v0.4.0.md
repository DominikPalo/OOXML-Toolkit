**OOXML Toolkit 0.4.0** adds a **Save button** to the tab bar and tells you when an open file is **changed by another program**, so you never overwrite someone else's edits by accident.

![Animated tour](https://raw.githubusercontent.com/DominikPalo/OOXML-Toolkit/main/docs/demo.gif)

## What's new

- **Save and Save As buttons.** The tab bar has a **Save** button next to Compare, enabled while the active document has unsaved changes. It does the same as `⌘S` / `Ctrl+S`: Inspector drafts are committed first and the malformed-XML check still applies. The arrow next to it opens a menu with **Save** and **Save As…** (with their shortcuts); Save As… also works on an unmodified document, so you can copy a clean file.
- **Files changed by another program.** If PowerPoint, Word, a sync client or anything else modifies a file that is open, a yellow bar offers to **Reload** it and the tab shows a ⚠. Saving over a changed file asks first, so the other program's edits are never overwritten by accident. **File → Reload from Disk** re-reads a file at any time and keeps the tab and its selection (unsaved edits are discarded, after asking). The app's own saves never trigger the warning.

Good to know: files are checked every second and whenever the window regains focus, by modification time and size. The browser build does not watch files.

### First launch — the builds are not notarized yet

- **macOS:** drag the app from the `.dmg` to *Applications* and open it once — macOS blocks it. Then open
  **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to
  “OOXML Toolkit was blocked”. (macOS 14 and earlier: right-click the app → **Open** instead.)
  From a terminal, this does the same: `xattr -dr com.apple.quarantine "/Applications/OOXML Toolkit.app"`.
  Notarization needs a paid Apple Developer ID; until then this one-time step is required.
- **Windows:** SmartScreen may warn about an unrecognised app — choose **More info → Run anyway**.
- **Linux:** `chmod +x OOXML-Toolkit-0.4.0-linux-x86_64.AppImage && ./OOXML-Toolkit-0.4.0-linux-x86_64.AppImage`.
  If it does not start, install FUSE 2 (`libfuse2` / `fuse2`).

## About OOXML Toolkit

View, edit and compare Office Open XML packages (`.docx`, `.xlsx`, `.pptx` and friends) and OpenDocument packages right down to the XML: a tree of every part and element, source editor and inspector, worksheet / document / slide previews, text / regex / XPath search, side-by-side comparison, bookmarks and history, and a package check. See the [README](https://github.com/DominikPalo/OOXML-Toolkit#readme) and the [user guide](https://github.com/DominikPalo/OOXML-Toolkit/blob/main/docs/guide.md).

## Known limitations

- Password-protected Office files and legacy binary formats (`.doc`, `.xls`, `.ppt`) cannot be opened.
- OpenDocument files have no slide, document or worksheet preview yet.
- The package check verifies structure, not ECMA-376 schema validity.
- The slide and worksheet previews are simplified (no fonts/fills/charts; raw cell values).
- Builds are not notarized (see above) and there is no auto-update yet.
