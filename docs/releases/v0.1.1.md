Patch release that fixes the **macOS builds**, which could not be opened after a browser download in 0.1.0.

## Fixed

- **macOS: “OOXML Toolkit is damaged and can't be opened.”** The 0.1.0 app still carried the original
  Electron binary's signature, which is invalid for the re-packaged bundle, so Gatekeeper called it
  damaged once a browser had quarantined the download. The app is now signed ad hoc with a valid
  signature, and the release workflow fails if that signature is ever invalid.

### First launch — the builds are not notarized yet

- **macOS:** drag the app from the `.dmg` to *Applications* and open it once — macOS blocks it. Then open
  **System Settings → Privacy & Security**, scroll down and click **Open Anyway** next to
  “OOXML Toolkit was blocked”. (macOS 14 and earlier: right-click the app → **Open** instead.)
  From a terminal, this does the same: `xattr -dr com.apple.quarantine "/Applications/OOXML Toolkit.app"`.
  Notarization needs a paid Apple Developer ID; until then this one-time step is required.
- **Windows:** SmartScreen may warn about an unrecognised app — choose **More info → Run anyway**.
- **Linux:** `chmod +x OOXML-Toolkit-0.1.1-linux-x86_64.AppImage && ./OOXML-Toolkit-0.1.1-linux-x86_64.AppImage`.
  If it does not start, install FUSE 2 (`libfuse2` / `fuse2`).

## About OOXML Toolkit

View, edit and compare Office Open XML packages (`.docx`, `.xlsx`, `.pptx` and friends) right down to the
XML: a tree of every part and element, source editor and inspector, worksheet / document / slide previews,
text / regex / XPath search, side-by-side comparison, bookmarks and history, and a package check. Everything
in [0.1.0](https://github.com/DominikPalo/OOXML-Toolkit/releases/tag/v0.1.0) is included — see the
[README](https://github.com/DominikPalo/OOXML-Toolkit#readme) and the
[user guide](https://github.com/DominikPalo/OOXML-Toolkit/blob/main/docs/guide.md).

![Animated tour](https://raw.githubusercontent.com/DominikPalo/OOXML-Toolkit/main/docs/demo.gif)

## Known limitations

- Password-protected Office files and legacy binary formats (`.doc`, `.xls`, `.ppt`) cannot be opened.
- The package check verifies structure, not ECMA-376 schema validity.
- The slide and worksheet previews are simplified (no fonts/fills/charts; raw cell values).
- Builds are not notarized (see above) and there is no auto-update yet.
