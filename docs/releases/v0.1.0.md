First public release of **OOXML Toolkit** — a desktop app to view, edit and compare Office Open XML packages (`.docx`, `.xlsx`, `.pptx` and friends) right down to the XML.

![Animated tour](https://raw.githubusercontent.com/DominikPalo/OOXML-Toolkit/main/docs/demo.gif)

### First launch — the builds are not code-signed yet

- **macOS:** open the `.dmg`, drag the app to *Applications*, then **right-click → Open** the first time
  (or run `xattr -dr com.apple.quarantine "/Applications/OOXML Toolkit.app"`). macOS may otherwise say
  the app “is damaged” or comes from an unidentified developer.
- **Windows:** SmartScreen may warn about an unrecognised app — choose **More info → Run anyway**.
- **Linux:** `chmod +x OOXML-Toolkit-0.1.0-linux-x64.AppImage && ./OOXML-Toolkit-0.1.0-linux-x64.AppImage`.
  If it does not start, install FUSE 2 (`libfuse2` / `fuse2`).

## What's in 0.1.0

- **Tree + details** — every part of a package and every XML element in a lazily-loaded tree, or the
  relationship graph; source editor, element inspector, hex and image views.
- **Previews** — worksheet grid with formula bar, Word text outline, slides with shapes, pictures and notes.
- **Editing** — edit XML in the editor or the inspector, duplicate / move / insert / delete elements,
  add / replace / rename / delete parts, with undo/redo across all of it. Saving only rewrites what you changed;
  everything else is copied byte-for-byte.
- **Comparing** — two files, or your unsaved edits against the saved file, as a part-level report and a
  split or unified XML diff; export a Markdown report.
- **Finding things** — text / regex / XPath search across all parts, *go to part* (`⌘P` / `Ctrl+P`),
  bookmarks with notes, recent files with pinning, session restore.
- **Package check** — malformed XML, dangling relationships, missing content types, unreferenced parts.
- Light / dark theme, drag & drop, file associations, command-line open.

See the [README](https://github.com/DominikPalo/OOXML-Toolkit#readme) for worked examples with
screenshots and the [user guide](https://github.com/DominikPalo/OOXML-Toolkit/blob/main/docs/guide.md)
for the full reference.

## Known limitations

- Password-protected Office files and legacy binary formats (`.doc`, `.xls`, `.ppt`) cannot be opened.
- The package check verifies structure, not ECMA-376 schema validity.
- The slide and worksheet previews are simplified (no fonts/fills/charts; raw cell values).
- Builds are unsigned (see above) and there is no auto-update yet.
